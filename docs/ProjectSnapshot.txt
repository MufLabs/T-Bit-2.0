## Application Entry Points

- `server.ts` - local Express API, storage endpoints, AI providers, Q-Vault services.
- `index.ts` - Node-side 1:1 storage demo entry point.
- `src/main.tsx` - React bootstrap.
- `src/App.tsx` - main Q-Vault / Quantum Engine frontend shell. This file is a
  deliberate monolith that contains, among others, the settings modal, first-run
  setup / onboarding, Q-Vault live map, chat console, semantic search controls and
  code graph controls that were previously listed as separate components.
- `src/index.css` - global UI styling.

## Storage Core

- `TBitFileSystem.ts` - physical framed storage, V/Anti-V write/read behavior.
- `TBitStorageService.ts` - high-level storage service.
- `AllocationMap.ts` - occupied-region tracking and collision/overlap protection.
- `EncryptionKeyManager.ts` - AES-GCM key handling and migration support.
- `textEncoding.ts` - UTF-8/Unicode-safe encoding helpers.
- `tbitRuntimePaths.ts` - runtime path helpers (spaces, vault roots).
- `containerHealth.ts` - health metrics.
- `healthReconciliation.ts` - health/index reconciliation helpers.
- `networkSync.ts` - network state, record export/import and anti-entropy.

## AI / Orchestration

- `AiProvider.ts` - provider contract.
- `AiProviderFactory.ts` - provider selection (10 provider descriptors).
- `OpenAICompatibleProvider.ts` - OpenAI-compatible provider implementation.
- `UniversalAiProviders.ts` - universal provider definitions.
- `TBitAiBridge.ts` - T-BIT tool bridge for AI (legacy prompt/tools).
- `TBitChatEngine.ts` - chat orchestration (SIMPLE route with 2-step tool loop).
- `TBitLocalToolExecutor.ts` - local T-BIT tool execution (7 tools).
- `TBitPrompts.ts` - system prompt helpers.
- `TBitToolSchemas.ts` - tool schema definitions (includes tbitSymbolicTools).
- `TBitSymbolicBridge.ts` - symbolic oracle bridge and `operar_simbolicamente` schema.
- `aiPermissions.ts` - AI permission policy.
- `guardianObserver.ts` - Guardian Observer analysis layer.
- `webResearch.ts` - T-BIT web research tooling.

## Engineering Records

The `engineering/` directory contains engineering change requests, audit notes,
reports, and workflow artifacts. These are supporting records, not the canonical
book or current summary. `engineering/Ai_evolution_roadmap.md` is the governing
AI evolution roadmap; `engineering/reports/AI-EVOLUTION-BASELINE.md` is the
verified Phase 0 baseline (with a 2026-10-07 verification addendum).

`.github/agents/` contains 18 declarative `.agent.md` specifications
(MUF Labs Engineering Framework). They are specifications, not a runtime.
