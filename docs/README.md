# T-BIT / Q-Vault Documentation

This folder is the canonical documentation location for the current T-BIT /
Q-Vault project.

## Current Documents

- `T-BIT_BOOK.md` - main technical book and complete project narrative.
- `T-BIT_PHASE_SUMMARY_2026-08-11.md` - updated phase summary.
- `T-BIT_EVALUACION_FINAL_2026-08-11.md` - current evaluation replacing old `Evaluacion` files.
- `ProjectSnapshot.txt` - curated project map and active source overview.
- `CHANGELOG.md` - registro de cambios del proyecto (nuevo, 2026-10-07).

## Documentation Rules

- Keep current project documentation in this `docs/` folder.
- Do not maintain duplicate phase summaries or duplicated evaluation files.
- Use `T-BIT_BOOK.md` as the main historical and architectural source.
- Use `ProjectSnapshot.txt` for a quick map of active code, components, services,
  and generated/runtime exclusions.
- Use `CHANGELOG.md` as the single source of truth for recorded changes.
